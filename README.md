# BookingApp

A simple full-stack Booking application, built as a learning project to understand the complete flow from UI to database and back.

## Tech Stack

- **Frontend:** Angular, TypeScript, HTML/CSS
- **Backend:** ASP.NET Core 8 Web API, C#
- **Database:** SQLite via Entity Framework Core

## Project Structure

```
BookingApp/
├── backend/    ASP.NET Core 8 Web API
└── frontend/   Angular application
```

## Features

- View all bookings
- View a single booking
- Create a booking
- Edit a booking
- Delete a booking

## Status

Project scaffolding in progress — implementation follows a step-by-step plan.
